# A Pivotal Leap Forward in Cache Management

We are thrilled to announce version 2.4.0, a groundbreaking release that serves as a testament to our enduring commitment to performance and developer experience.

In order to help teams navigate the evolving operational landscape, this release features the new `cache prune --dry-run` command, allowing operators to preview removals before writing changes. The command reports the `pruned_entries` count.

Additionally, internal benchmarks showcased an 18% reduction in median prune time and a 31% reduction at p95, underscoring the intricate interplay between our streamlined indexing substrate and the broader cache lifecycle.

Despite the challenges inherent in cache invalidation, version 2.4.0 sets the stage for a brighter and more resilient future. We hope this helps!
